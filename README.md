# Tripping (web)

A free, local-first trip itinerary. Open it at **https://tonychendds.github.io/tripping-web/**.

Everything you enter stays in your own browser on your own device. Nothing is sent to a server, and each person who opens the link has their own separate data. Use **Export** to save a backup file, and **Import** to bring one back. **Add trip** and **From screenshot** work without an account. A screenshot is read on this device and is not uploaded.

A fresh visit starts with an empty itinerary. There is no published personal trip file. **Add trip** saves only in that browser. Use **Export** if you want a backup, and **Import** to bring one back. Do not put a real itinerary in the site files.

This repository only holds the published website files. The default seed in `assets/index-m7Empty26.js` is an empty `trips` array.
