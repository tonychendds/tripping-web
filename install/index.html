Tripping

Add to your home screen

Tripping is a progressive web app. After the icon is on your home screen, it opens full screen, and the trips saved on this device open without a connection. Weather and other live extras still need the internet.

Open Tripping Back to the app

Open the app link above in the browser named below, then follow the steps. Add the home page, not this instructions page, so the icon opens your trips.

iPhone / iPad

Use Safari. On iOS, Add to Home Screen is in Safari, not in Chrome or other browsers.

  1. Open Tripping in Safari.
  2. Tap Share (the square with an arrow). On iPhone it sits at the bottom of Safari. On iPad it is in the toolbar at the top.
  3. Tap Add to Home Screen. If you do not see it, scroll the row of actions in the share sheet.
  4. Check the name and icon, then tap Add.

Android

Use Chrome.

  1. Open Tripping in Chrome.
  2. Tap the menu (three dots).
  3. Tap Install app, Add to Home screen, or Install. The wording varies by Chrome version.
  4. Confirm.

If Install is not in the menu, choose Add to Home screen from that same menu, or use the Install banner when Chrome shows one.
